# Binder Town สำหรับ Windows

แอปเกม Binder Town บน Windows — เล่นเกมเดียวกับบนเว็บ ใช้ไอดีเดิมได้เลย

## ดาวน์โหลด
👉 [BinderTown-Setup.exe](../../releases/latest/download/BinderTown-Setup.exe)

## ต่างจากเล่นบนเว็บยังไง
- ย่อหน้าต่างหรือเปิดโปรแกรมอื่นทับ เกมไม่ช้าลง AUTO ฟาร์มต่อเต็มที่
- เบราว์เซอร์จะไม่พักหรือปิดแท็บเกมเอง
- โน้ตบุ๊กที่มีการ์ดจอแยก ใช้การ์ดจอแยกให้อัตโนมัติ
- เกมอัปเดตเองทุกแพท ไม่ต้องดาวน์โหลดใหม่

## ติดตั้ง
1. ดาวน์โหลดไฟล์ `BinderTown-Setup.exe` แล้วดับเบิลคลิก
2. ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
   (ขึ้นเพราะแอปยังไม่มีใบรับรองผู้เผยแพร่ ไม่ใช่ไวรัส)
3. เปิดเกมจากไอคอน Binder Town บนเดสก์ท็อป

ปุ่มลัด: **F11** เต็มจอ · **F5** รีเฟรช
